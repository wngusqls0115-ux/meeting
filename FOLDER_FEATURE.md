# Folder feature v2

Added logical folders for meeting organization.

- Create arbitrary folders
- Built-in `전체 회의` and `미분류`
- Folder counts
- Search inside selected folder
- Assign folder during import
- Change folder during edit
- Rename folder
- Delete folder without deleting meetings
- Existing meeting DB migrates automatically by adding `folder_id`

Examples:
- 공장 레이아웃
- 파일럿 설비
- HSE
- 특허
- 주간회의
